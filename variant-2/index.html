Brain.Protocol Open Spec • v0.1

AI Agent Memory

Give your agent
a structured brain.

An open specification for building AI agent workspaces that are readable by humans, writable by machines, and versioned by git.

Markdown-first Human-readable Version-controlled LLM-agnostic No vendor lock-in

Not a framework.
A convention.

Brain Protocol defines how an AI agent's memory should be organized on disk. No databases, no vector stores, no proprietary formats. Just directories and markdown files.

A brain is a git repository. Everything the agent knows — people, projects, tasks, history — lives in structured markdown with frontmatter metadata. The agent reads on boot, writes during sessions, commits the diff.

📄

Plain text only

Every piece of memory is a markdown file. Open it in any editor, grep it, version it. No lock-in.

🏠

Git is the database

Memory has history. Diff two sessions, revert a decision, audit every change the agent made.

🔑

Frontmatter metadata

Machine-readable context on every file: type, tags, relationships, timestamps.

🤖

LLM-agnostic

Claude, Gemini, GPT, Mistral — any model that can read a directory speaks Brain Protocol.

The directory layout.

Directories
wiki/ Entities: people, companies, projects, tech, domains
diary/ Temporal log — what happened and when
todo/ Open tasks, tracked in structured markdown
inbox/ Incoming items to be processed by the agent
boot/ System config: identity, agents, tools, protocols
tools/ API wrappers, automation scripts, integrations
