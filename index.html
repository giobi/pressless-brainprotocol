// 01 — What

Not a framework.
A convention.

Brain Protocol defines how an AI agent's memory should be organized on disk. No databases, no vector stores, no proprietary formats. Just directories and markdown.

A brain is a git repository. Everything the agent knows — about people, projects, tasks, history — lives in structured markdown files with frontmatter metadata. The agent reads them on boot, writes during sessions, commits the diff.

01 //

Plain text only

Every piece of memory is a readable markdown file. Open it in any editor, grep it, version it.

02 //

Git is the database

Memory has history. Diff two sessions, revert a bad decision, audit what the agent changed.

03 //

Structured metadata

Frontmatter provides machine-readable context: type, tags, relationships, timestamps.

04 //

LLM-agnostic

Works with Claude, Gemini, GPT, Mistral — any model that can read a directory.

// 02 — Structure

The directory layout.

brain/
├── wiki/ // entities: people, companies, projects, tech
│  └── projects/client-x/index.md
├── diary/ // temporal log — what happened and when
│  └── 2026/03/02.md
├── todo/ // open tasks
├── inbox/ // incoming — to be processed
├── boot/ // system config: identity, agents, tools
└── tools/ // API wrappers and automation scripts
